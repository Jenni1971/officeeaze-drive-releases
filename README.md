# OfficeEaze Drive for Windows: releases

This repository holds only the release files (the installer and the update packages) for
OfficeEaze Drive for Windows. Installed copies of the app check its Releases for updates.

To install: download **OfficeEazeDrive-prod-Setup.exe** from the latest release, or use the link
OfficeEaze support sends you.

The source code is not here. Questions: OfficeEaze support.
